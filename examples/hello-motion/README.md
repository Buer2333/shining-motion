# hello-motion

A runnable example of `@shining-motion/core` and `@shining-motion/2d`: one card that fills in, gets stamped, and tilts into perspective. It uses no images, sound, fonts or footage, so everything you see is drawn by code.

```sh
npm install   # once, at the repo root
npm run studio   # preview
npm run render   # writes out/hello-motion.mp4
```
